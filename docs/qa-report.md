### 诚实边界

真实编辑引擎不是完整 Helix：UTF-16 inclusive 索引、无软换行；正则为 JS Unicode / Rust 常用交集，不支持环视、反向引用、零宽匹配；对象为简单词法结构，不解析 Tree-sitter；两个空格缩进；不访问系统剪贴板。

全量数组 / 冒号参数配置可以编辑、按键回忆和原生导出，但实际编辑轨道不执行数组、文件、LSP、窗口、buffer、终端或 shell 命令，也不将它们算作成功。原生学习路径在界面和 README 中明确说明。移动视口不等于实体手机或完整无障碍认证。
