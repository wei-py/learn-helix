# Helix 练习场

中文 Helix 学习应用：**按指定文章组织的实操与回忆题 + 完整默认键位 / 命令查阅**。它不是在网页里假装运行 LSP、文件系统或终端的编辑器克隆。

## 出题依据

以 Tmacy 的[《【推荐】后现代风格文本编辑器-Helix》](https://www.cnblogs.com/tmacy/p/17916523.html)为学习主线：

- **36 个实操练习**按原文章节排列，并链接到对应章节。保留原有课程 ID 和进度；新增原文的批量 `(use)` → `[use]` 与 `[[[abc]]]` → `[([abc])]` 两个环绕示例。
- **38 道文章回忆题**覆盖安装、模式、移动、修改、选择、搜索、轻模式、选择器 / 提示、环绕、文本对象、语法跳转及寄存器。题目为文章场景改编，不声称覆盖文中每一个表格条目。
- 「文章回忆 / 下一题」仅在该题库内前进，跳过已掌握题；未答题也可跳过，末尾回绕，全部掌握后仍在文章题库复习。文章进度单独计数；旧目录自测记录保留，但不会被算成文章掌握。
- 完整目录仍可查阅、逐项发起命令 / 按键自测；从目录进入的自测标明范围，「下一题」返回文章题库。
- 文章是选题依据，当前键位与命令语义仍以固定 Helix 25.07.1 为准。纠正原文 `:totur` 为 `:tutor`，不采用存在版本差异的 `vgl` 示例；picker / prompt 使用各自的键表，不套用编辑模式自定义键位。
- LSP、Tree-sitter、文件、窗口及 shell 等依赖原生环境的内容只出知识题，不伪装成网页已执行。

## 报纸式阅读界面

「Helix 练习报」保留 Helix 练习场的全部学习功能，以暖白报纸、墨黑文字、少量赭红强调色重新排版：通栏报头、课程索引、分栏指导与细线栏目层级，替代圆角卡片仪表盘。现有 36 课、38 道文章题、671 个默认叶绑定与 394 个命令；原有课程和目录进度保留。

编辑区采用浅纸色等宽排版，反白区域标示选区，赭红标示主选区或插入点；目标预览使用相同规则。目录搜索与分页、按键回忆、参数表单、键位设置及配置导出统一为报纸式控件。窄屏改为单栏与可收起课程索引，保留键盘焦点、Tab 导航、触屏输入和减少动态效果偏好。

标题使用本地宋体 / CJK 衬线字体栈，正文与代码使用系统字体；不加载外部字体服务。

入口为「关卡 / 目录 / 文章回忆」和「键位 / 导出 / 帮助」。首页关卡地图按文章章节分组，整张卡片可点击或用 Tab / Enter 进入；展示题目、任务简介、步数、当前课与完成状态。全部 36 课直接开放，不要求前置通关、速度或正确率；已完成课程可重复练习。侧栏分类筛选地图，练习页保留快速切课列表、「返回关卡地图」与下一课；地图提供继续当前课。原理、写法和范围说明按需展开。

### 滚动与导航

- `index.html` 是页面 Layout：持久的 `#scroll-root` 包住 `#app`，仅该容器负责整页纵向滚动。`body` 不滚动，`main` 和业务区不创建第二个页面滚动条；桌面 36 课侧栏随页面正常流动。
- `src/navigation.js` 是轻量原生 Router：轨道、课程和回忆题写入浏览器历史；搜索、筛选和分页替换当前条目，不按每次输入堆积历史。普通进入置顶；目录「返回目录」和浏览器后退 / 前进恢复对应条目的筛选、页码和位置。每个历史条目用 `crypto.getRandomValues` 生成 128 位随机标识，兼容局域网 HTTP；刷新保留历史上下文，但滚动缓存不跨文档保存，未知旧条目位置为顶部，不会复用其他条目的位置。
- `src/scroll.js` 集中提供 `remember / restore / top / scrollTo / scrollToAnchor / observe / setOverlay / dispose`。位置仅在内存保留最近 80 个条目，不写入 localStorage。普通重绘保持原位置，只在内容确实缩短时由容器自然钳制。滚动订阅使用 passive + requestAnimationFrame 合并，并返回清理函数；路由退出清理局部列表、抽屉监听和测量缓存，文档退出清理 Router / 管理器。
- 设置、帮助和导出使用独立的有界原生 Dialog；窄屏课程索引是独立抽屉。覆盖层同时锁住 body 和页面根滚动，关闭还原打开前的 overflow 与位置。抽屉禁用背景焦点、约束 Tab 并支持 Esc。顶栏 sticky 的祖先是页面根容器。
- **应用记录列表超过 80 项必须使用共享虚拟列表** `src/virtual-list.js`；设置 normal / select 各 322 项按可见范围加 3 行 overscan 渲染，而非隐藏整个 DOM。设置 Dialog 本身是唯一纵向视口，列表仅包含行与占位间距，不再嵌套纵向滚动。ResizeObserver 测量实际高度，最多 1000 项的弹窗生命周期缓存跨输入重绘保留；可见区上方尺寸变化补偿位置，当前聚焦行单独保留，Tab 可跨未挂载行。关闭 / 导航断开观察器与监听并清空缓存。目录每页 24 项、课程最多 36 项低于阈值；原生 select / datalist 的选项属于输入元数据，不是额外业务滚动列表。
- 编辑器、目标预览、来源代码和导出预览有明确高度上限与局部代码溢出；弹窗 / 抽屉 / 局部内容使用 overscroll 边界，移动滚动启用 momentum。正文锚点统一经管理器处理，设置 `scroll-margin-top: 84px` 避让顶栏；仅锚点与返回顶部可平滑滚动，并尊重 reduced-motion。返回顶部在 600px 后显示，`z-index: 200`，不抢键盘焦点。
- 当前没有表格、固定表头 / 列、图片、异步请求或 skeleton；相关条件项不适用，不新增空表格组件、图片占位或虚假网络状态。错误参数仍由真实编辑引擎报告，保持当前页面上下文。桌面模拟不能证明真机 iOS / Android 惯性；29 条适用性及实测边界见 [验收记录](docs/minimal-scroll-qa.md)。

最新验收包含目录往返上下文、末行连续输入、覆盖层锁定、窄屏局部溢出与真实局域网 HTTP 导航。性能样本出现一条 78ms self long task，无法区分应用工作与自动化开销；不能据此宣称零长任务或性能认证，不为消除未知归因而修改编辑校验语义。

## 本地运行

需要 Node.js 22.12+（或 20.19+）与 npm。

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

打开 Vite 打印的 Local 地址；当前保留的开发服务为 **http://localhost:5174/**。开发服务器绑定 `0.0.0.0`；同一局域网可使用打印的 Network 地址。

应用仍为静态站点，没有后端、账户、数据库或常驻原生编辑器进程。构建产物在 `dist/`，可静态部署。源码运行时是原生 ES modules 与 DOM；Vite 提供开发与构建工具。

### GitHub Pages 发布

仓库 Settings → Pages → Source 选择 **GitHub Actions**。将代码及 `.github/workflows/deploy.yml` 推送到 `main` 后，工作流会安装依赖、构建并发布 `dist/`；也可在 Actions 页面手动触发。

构建使用 Pages 提供的 `base_path`，兼容仓库子路径与用户主页。部署成功后，在 Settings → Pages 查看访问地址；后续推送到 `main` 会自动更新。

## 三条学习轨道，三个不同的覆盖口径

| 轨道 | 精确范围 | 完成意味着什么 |
| --- | --- | --- |
| 实际编辑 | **36 课：11 基础 + 25 进阶**，按原文章节排序 | 实际操作步骤、文本、模式、全部选区和指定主选区均符合目标；不是按对一个键就完成 |
| 文章回忆 | **38 道场景 / 理解题**，仅从指定文章改编 | 理解文中操作与适用场景；不代表浏览器已执行原生功能 |
| 完整目录 / 逐项自测 | **671 个默认叶绑定**（normal 322、select 322、insert 27），**394 个命令**（305 静态 + 89 冒号命令），另有 69 个命令别名及 26 个模式内前缀节点 | 查阅完整版本与当前配置，按需自测；不纳入文章回忆计数 |

目录精确固定为 **Helix 25.07.1**。静态命令中 **44 个没有默认键位**，仍可搜索、学习、答题及新增自定义绑定；不是只收录已经绑定的 261 个不同静态命令。全部 394 个命令有中文学习含义，同时保留上游英文说明，便于审计。

671 指三种**编辑模式**的完整默认键图叶子，包括嵌套前缀与继承后 select 映射；不包括 picker、prompt、popup、补全菜单等专用界面键表，也不把无限可能的文字输入字符算作绑定。这些专用界面当前不通过本应用编辑模式设置重映射；官方参考和明确范围见 [完整研究记录](docs/helix-coverage-research.md)。

### 完整目录怎么用

- 打开「目录」，按命令、中文含义、英文说明、键、前缀搜索，按模式与分组筛选；分页浏览全部内容。
- 「命令」不保留键位页的隐藏模式筛选，因此未绑定命令与 `:write` 等命令行命令都能找到。
- 目录的「场景知识题」用官方含义提问，从命令名中选择；文章回忆使用独立编写的场景和解析。「按键回忆」检查指定叶绑定当前保存的键，不使用已移走的旧键。
- 已禁用的绑定不会凭空要求不存在的按键，也不会伪造完成标记。可恢复或新增绑定后练习。
- 浏览器无法捕获的键和触屏输入，可用回忆题的「填写 Helix 键序列」表单检查。知识与编辑进度独立保存、分别计数。

## 实际编辑：不仅是移动和删除

点击编辑区使用物理键盘，或点击本课按键按钮。屏幕按钮与键盘使用同一份当前绑定匹配器；错误的受支持操作会真正改变文本，不会替换成答案。

每课指导栏都有默认收起的「查看答案」：按顺序列出**当前已保存键位**、所在模式、原样文字 / 正则 / 字符 / 文本对象、计数和参数提交 Enter；命名寄存器及宏明确指向当前「寄存器…」控件。移除全部可用绑定时会要求先配置，不伪造默认键。答案合并原目标预览，显示独立书写的最终文本、模式、全部选区及主选区；仅展开阅读，不执行、代填或记进度。目录中的按键 / 命令回忆题仍保留各自的答案入口。

25 个进阶挑战覆盖：

- 正则多选与同时改名；分割选区、按正则保留 / 排除、逐行拆分。
- 多插入点与退格；主选区轮换、只保留主选区、不同长度选区内容轮换。
- 数字计数与第二个字符查找、find / till 包含边界的区别。
- 正则搜索、前后跳转与回绕、选择模式追加搜索结果。
- 词 / WORD、inner / around、嵌套计数文本对象；添加、替换与删除包围。
- 命名寄存器 yank / paste、用寄存器替换选区、逐字符 replace、change 后同时输入。
- 包含换行的整行删除、多行缩进 / 反缩进、合并行并选择连接空格。
- 大小写转换、真实多选撤销 / 重做、录制及重复执行实际操作宏。
- 原文环绕例题：用正则多选批量替换 `(use)` 的包围；计数 2 只替换 `[[[abc]]]` 的第二层符号。

### 操作键与参数是两件事

正则、目标字符、文本对象或包围字符是必需参数：先按命令快捷键，再在参数表单里**自己输入并按 Enter 执行**，焦点回到编辑区。`c`、`d`、`y`、粘贴及宏命令的寄存器是可选参数，直接按键使用默认寄存器，不再强制弹出表单；需要命名寄存器时，点对应命令旁的「寄存器…」再输入并执行，相关步骤会提示这一入口。运行时不会从课程的 `step.args` 自动取答案。无效参数报错；有效但不正确的参数作用于实际状态，不会被改成预期参数，也不会因此通过课程。

「正则多选与批量改名」（现第 16 课）的默认键位：点击编辑区 → `%` → `s` → 输入 `cat` → `Enter` → `c` → 输入 `dog` → `Esc`。`c` 会直接进入插入模式，三个选区同步改为 `dog`；改键后以当前步骤显示的按键为准。

普通 / 选择模式可直接键入数字前缀；触屏也有「下一条命令计数」输入框。没有输入计数与显式输入计数会正确区分，例如内容轮换的默认整组选区行为。参数表单的计数仍需用户决定。

插入模式可直接输入，也可用「触屏 / 中文输入」文字表单或粘贴。物理键盘与屏幕命令共用 `src/practice-input.js` 的匹配状态：只有尚未完成的自定义前缀保留待续按键，已匹配命令在执行前即消费序列；Backspace、Enter、Ctrl+h 后继续输入不会把字符接到旧命令后。有效映射优先于普通文字 / 数字计数，已移走的旧键不会通过硬编码退格或退出回退重新生效。Tab / Shift+Tab 始终保留网页焦点导航；对应编辑器操作可通过屏幕输入途径使用。Esc 优先匹配当前模式配置，未匹配时可取消未完成前缀；参数表单可点「取消」。

macOS 的 Option 等同 Alt。练习编辑区与按键回忆共用 `keyFromEvent`：当 Option 产生 `å / ß / ∂ / ƒ` 等非 ASCII 字符或 `Dead` 死键时，按 `KeyboardEvent.code` 恢复 US / ABC 对应键位，再匹配 `A-a / A-s / A-d / A-f`；保留 Shift / CapsLock 的字母大小写，以及数字、标点的 Shift 符号。仅在 macOS、按住 Option 且主键被转换时恢复，不把其他布局已提供的 ASCII 逻辑键强制改成物理键。不承诺恢复任意非 US 布局的 Option 符号；不认识的物理键保持原有处理。搜索、参数及文字输入框不拦截 Option 输入；需要在练习中输入这些字符时可用文字表单或粘贴。此修复不修改终端的 Option / Meta 配置。

文字首次达到目标后，在执行下一步命令前仍可修改：例如 `dx` → Backspace → `og`，或 `dogx` → Backspace，都按实际缓冲区重新检查文字步骤。多选区退格仍真实删除各插入点前的字符（包括空插入点前的分隔符），不会为通过课程而忽略删除；最终文本、模式与全部选区必须符合目标。重新练习可恢复本课原始状态。

完成依据包括实际状态，不只是步骤：所有多选区、虚拟 EOF 位置和主选区都参与目标检查。文件末尾的虚拟位置会显示为可选中的空白格；例如删除最后一段后继续插入，不能偷偷退到前一个字符。

## 全目录自定义键位

顶部「键位」编辑全部三模式默认叶绑定以及新增的命令别名。支持模式切换、分组 / 前缀筛选、中文 / 命令 / 键搜索、逐项恢复、留空移除、新增绑定和恢复默认。

### 同一数据贯穿提示、匹配、回忆与导出

例如把 normal 的 `move_char_right` 从 `l` 改为一个空闲序列 `F6 h`：

1. 课程提示和按钮显示 `F6 → h`，实际匹配也改用该序列。
2. 原 `l` 不再执行这个绑定；其他没有移除的真实别名（例如方向键）仍可执行。
3. 改动过的有效别名优先用于提示；有多个改动别名时，按目录顺序稳定选择，刷新后不变。
4. 按键回忆使用保存后的新键；改动的叶绑定会清除对应旧按键回忆标记。
5. TOML 在 `[keys.normal."F6"]` 下输出 `"h" = "move_char_right"`，同时把移走的旧 `l` 显式设为 `no_op`。

新改键会对**全部目录**做同模式重复 / 前缀冲突检测，不会静默覆盖原有项；想取代内置绑定，必须先清空或移动冲突项。不同模式可用同一序列。恢复默认只恢复键位，不清除已完成编辑课程。

### 键和命令写法

- 单字符、原生特殊键、`F1`–`F24`；用空格分隔任意深度的嵌套序列，不再限制三键。
- Helix 修饰符 `C-`、`A-`、`S-`、`Meta-`；`Cmd-` / `Win-` 规范化为 `Meta-`。**`A-c` 与 `A-C` 是不同键**。`A-S-c` 规范化为 `A-C`；显式 Helix 写法 `C-H` 保留大写。`Ctrl+H` 等便捷界面别名会规范化。
- 例如 `C-w h`、`space w n C-v`、`A-minus`。支持 `Escape` / `Enter` / 方向键等界面别名，导出规范原生写法。
- 配置合法性与浏览器可捕获性分开：有效的 `C-r`、`C-w`、`tab` 等默认键均能保存 / 导出，不因浏览器保留键被删除；界面提示可能拦截，回忆题提供序列表单。
- 新增命令可为静态名（`select_regex`）、冒号命令含参数（`:open "file name.txt"`），或 JSON 命令数组（`["move_char_right","delete_selection"]`）。校验每一项是否为官方命令；数组与依赖系统环境的命令用于原生导出，不在编辑挑战中伪装执行。

## 导出到真实 Helix

「导出」提供 TOML 预览、复制和下载 `helix-keys.toml`。这是**完整三模式键位片段，不是整个 config.toml**；保留现有的 editor、theme 等设置，不要覆盖整个文件或重复表头。

常见路径为 `~/.config/helix/config.toml`；Windows 通常是 `%AppData%\helix\config.toml`。先备份，再合并到对应表。

导出覆盖全部当前默认 / 自定义键位，正确转义键名与嵌套表，保留命令数组和冒号参数。对移走、清空的默认叶子显式使用 `no_op`：它仅用于原生禁用旧键，**不是用来伪造编辑功能的占位命令**。没有移除的其他别名仍然有效。

原生 Helix 合并同一路径时保留内置 sticky 前缀属性；但 TOML 没有 `sticky=true` 配置项，不能把 sticky 属性迁移到新的前缀。应用承诺新的完整序列与命令映射，不承诺把原生 sticky 菜单机制搬到新路径。

## 保存与旧版本迁移

沿用 `localStorage['helix-lab-v1']`，记录内容版本升级为 2；不另开存储键丢弃原进度。v1 的 19 项设置与完成课程会迁移到完整目录：保留明确的自定义键，并禁用因新增完整默认图而冲突的其他默认叶子，显示迁移提示。例如旧自定义 `normal.right = "g h"` 保留，而原生 `g h` 叶子被移除；不会静默把用户设置重置掉。

旧 `select.normal` 专门迁移到 `exit_select_mode`（Esc），不误指向原生 `normal_mode`（v）；自定义退出键也保留，不误禁用 v。

损坏记录、未知进度、存储受限和写入失败都有防护；存储失败时继续使用本页配置并提示导出备份。知识 / 叶绑定回忆与编辑课程独立保存；「重置学习进度」清除两类完成标记，不改键位。数据只在当前浏览器，不上传、不同设备不同步。样式仅使用本地 / 系统字体，不向 Google Fonts 或其他字体服务发起请求。

## 诚实的边界与原生学习路径

- 真实挑战是明确支持的训练引擎，不是完整 Helix。支持集见 `ADVANCED_COMMANDS`；不支持的操作明确报错，不会只回显按键或当作已执行。
- 文本索引采用 UTF-16 inclusive 选区，不是完整 Unicode 字素 / rope 模型；不保证任意 emoji、组合字符、终端协议与原生一致。训练编辑区无软换行。
- 正则为 JavaScript Unicode 与 Rust regex 的常用交集；不支持环视、反向引用、零宽匹配及 Rust 专用语法。文本对象是词 / 简单括号 / 引号的词法规则，不解析 Tree-sitter，也不会忽略所有字符串内括号。
- 缩进训练为两个空格一级，寄存器不访问系统剪贴板；不是完整项目配置或所有寄存器类型的模拟。
- view / jump / window / buffer / LSP / DAP / 文件 / shell 等全部命令都在知识库，但依赖真实编辑器、文件、窗口、终端或语言服务器的部分不模拟执行。知识题不会把它们计为编辑挑战成功。

真实练习：在终端运行 `hx --tutor`，或在自己的项目中运行 `hx`；用 `hx --health` 检查对应语言服务器。使用完整目录查询当前映射与命令含义，再在真实文件与语言环境中操作。没有选择 PTY 后端，是为了避免把 ANSI 屏幕解析、文件 / LSP 生命周期和浏览器训练耦合为一个脆弱的编辑器克隆。
